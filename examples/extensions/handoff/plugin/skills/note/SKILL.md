# Leave a handoff note

Write the note as your last message, under these four headings, one or two lines each:

- **Goal:** what the work is for.
- **Done:** what is finished, with commits or paths.
- **Next:** the very next step.
- **Watch out:** what surprised you, or what would waste the next worker's time.

Say what you checked and what you didn't. Leave out what the code or the git log already says.
