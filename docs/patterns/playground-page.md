# A playground page to show a concept

Ask a worker to build a small interactive page that explains a new idea, then show it to the team.

Inês had to explain a new retry policy to her team, and a document wasn't landing. She asked a worker to build a
single html page: a timeline of requests, sliders for the backoff and the limits, and the failures drawn as they
would happen.

The worker built it and opened it beside its terminal with `tower show`. She tweaked it with the worker for a few
rounds, put it on the floor's shelf so it stayed one click away, and shared the file in the team's next meeting.
The page became the spec.
