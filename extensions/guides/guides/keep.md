# Keep a prompt for later

An idea that isn't for now goes in the floor's **drafts**: a prompt kept for later, which starts a worker when you are ready, and is then deleted.

Ask any worker:

> "Keep that idea as a draft, we'll do it next week."

It keeps it with `tower keep drafts`, and the draft gets a two-word **tag** to name it by (`ivory-otter`). The floor's Drafts tray in the sidebar lists them; open one to edit it, start a worker on it, or send it to a worker.

Drafts are one **collection**. A floor keeps others (reviews, policies, any you declare), and `tower kept` lists what each holds. Guides like this one are a collection too, kept for the whole tower.
